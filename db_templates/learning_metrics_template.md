## 필드 설명

- **run_id**: Run 고유 ID
- **total_tasks**: 전체 Task 수
- **executed_tasks**: 실행된 Task 수
- **skipped_tasks**: Skip된 Task 수 (= total - executed)
- **avg_activation**: 평균 활성화 값
- **final_quality**: 최종 품질 점수
- **target_quality**: 목표 품질 (기본 0.9)
- **error**: 품질 오차 (target - final)
- **avg_weight_delta**: 가중치 변화량 평균
- **total_time**: 총 실행 시간
- **total_cost**: 총 비용 (USD)

## 학습 효과 분석

### 패턴 1: 점진적 개선

```
Run-001 → Run-010 변화:
- 실행 Task: 15 → 12 (20% 감소)
- 시간: 88min → 29min (67% 단축)
- 비용: $10.50 → $5.10 (51% 절감)
- 품질: 0.75 → 0.91 (21% 향상)
```

**해석**: 신경망이 학습하면서
1. 불필요한 Task를 Skip (효율 증가)
2. 중요한 Task에 집중 (품질 향상)
3. Attention으로 토큰 절감 (비용 감소)

### 패턴 2: 수렴

```
가중치 변화량 (avg_weight_delta):
0.05 → 0.08 → 0.03 → 0.01

error:
0.15 → 0.08 → 0.05 → -0.01 (목표 달성!)
```

**해석**:
- 가중치 변화량 감소 = 최적값 수렴
- Error 감소 = 품질 목표 달성

## 알람 조건

- **품질 저하**: `final_quality < 이전 5개 평균 - 0.1`
- **비용 급증**: `total_cost > 이전 평균 * 1.5`
- **수렴 실패**: `avg_weight_delta > 0.1 for 10 consecutive runs`
